# Lian Port PC controls

**Controller recommended.** Use a controller for the game's original controls
and matching button prompts. Keyboard and mouse are an alternative. The
launcher's Motion & Controls tab shows controller prompts beside their PC keys.

Restart the launcher to use the latest staged runtime.

| Action | Binding |
|---|---|
| Move | WASD |
| Camera / gravity aim | Mouse |
| Float, then shift gravity toward aim | Left Shift; press again to shift |
| Reset gravity | C |
| Jump / speed fall / confirm | Space |
| Kick / gravity kick | Left mouse button |
| Stasis grab / throw | F |
| Special power | Q |
| Evade / dodge | Hold WASD and tap Left Alt, middle mouse button or right mouse button |
| Gravity slide | Hold Left Ctrl (sends L2 + R2) |
| L2 alone | R |
| Map / game menu (Options) | M or Esc |
| Contextual touchpad click | E or Tab |
| Pause / show confined cursor | Esc |
| Menu directions | Arrow keys / WASD |
| Confirm | Enter / Space |
| Back | Backspace; runtime dialogs also accept Esc |
| Click left stick / right stick | Z / V |
| Lian Port settings overlay | Insert |

For controller prompts: R1 = Left Shift, L1 = C, Square = left-click,
Cross/X = Space or Enter, Circle = F/Backspace, Triangle = Q, R2 = right/middle-click,
and **L2 + R2 = hold Left Ctrl**. R sends L2 alone; Left Alt also sends R2.
M sends Options, which opens the map/menu. E and Tab send a touchpad click.
Touchpad gestures and contextual finishers are not fully verified.

Click inside the game to resume mouse aiming. Esc menus keep the cursor inside the game;
Alt+Tab or minimizing releases it so you can use other apps. Controller support and gyro settings remain available.

The game still displays its original controller glyphs. M opened the map
in the Episode 3 candidate-13 live test; F (Circle) closed it in candidate 12. The menu can remember its
selected tab. Physical mouse aiming, combat, sliding/gliding and contextual
finishers still require broader gameplay checks.

The Episode 3 live replay also showed an evade animation after Left Alt + W,
with R2 press/release in the guest log, and C successfully returned Kat from
floating to the ground. Directional evasion in combat still needs wider testing.
